# Глоссарий

Определения пишем своими словами. Если термин требует подробного разбора, создаём отдельную заметку и ставим ссылку.

| Термин | Краткое определение | Связанная заметка |
|---|---|---|
| Scope | Явно согласованные границы тестирования: системы, методы и время |  |
| Поверхность атаки | Все доступные точки, через которые система может получить нежелательное воздействие |  |
| Уязвимость | Слабость, которая при определённых условиях способна привести к ущербу |  |
| Эксплойт | Способ или код, использующий конкретную уязвимость |  |
| Риск | Сочетание вероятности события и тяжести его последствий |  |
| False positive | Результат проверки, ошибочно принятый за реальную проблему |  |
