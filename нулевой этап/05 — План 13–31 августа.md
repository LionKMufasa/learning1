## Цель

Собрать одну понятную цепочку: `Linux-сервер → сеть → служба → HTTP → анализ трафика → автоматизация Python → безопасный аудит → отчёт`.

Проект — основной учебник. Внешние материалы из [[04 — Источники]] нужны только как дополнительное объяснение. Нагрузка: 2–2,5 часа в обычный день, 3–4 часа в выходной; математика — ещё 20–30 минут.

Если дата прошла, не перескакиваем вперёд: начинаем с первого урока со статусом `не начато` в [[06 — Трекер интенсива]].
