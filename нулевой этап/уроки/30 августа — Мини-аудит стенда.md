# 30 августа — мини-аудит стенда

**Цель:** провести безопасную проверку Ubuntu VM от scope до retest. **Результат:** технический отчёт с доказательствами и исправлениями.

## Методика

`Scope → discovery → ports → services → manual configuration review → findings → remediation → retest`. Проверяй SSH root login, метод входа, пользователей, службы, доступные порты, права конфигураций, обновления и журналы.

## Безопасная практика

Scope: один IP собственной VM, без перебора паролей, DoS и эксплуатации CVE. Сначала зафиксируй состояние; затем исправь только подтверждённые проблемы: отключи ненужную службу, ужесточи SSH в соответствии с сохранённым доступом, проверь права и обновления. Перед изменением обеспечь способ восстановления VM.

2. Как оценена вероятность и влияние?
3. Что именно подтвердил retest?
