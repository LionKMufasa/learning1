# 23 августа — Nmap и netcat

**Цель:** инвентаризировать собственный сервер. **Результат:** таблица `порт → протокол → служба → версия → необходимость`.

## Теория и команды

- `nmap VM_IP` — стандартный набор TCP-портов.
- `nmap -sV -p 22,80 VM_IP` — определение служб только на заданных портах.
- `nmap -p- VM_IP` — все TCP-порты; применяется только к своей VM.
- `nc -vz VM_IP 80` — проверка TCP-подключения без передачи прикладных данных.

`open` означает, что соединение принимается; `closed` — узел ответил, но слушателя нет; `filtered` — ответы блокируются или отсутствуют. Версия определяется эвристически и требует проверки.

## Безопасная практика

Письменно зафиксируй scope: один IP своей Ubuntu VM. Выполни команды выше, сравни результат с `ss -tulpn` внутри VM и вручную проверь HTTP через `curl`. Не сканируй домашнюю подсеть целиком.
