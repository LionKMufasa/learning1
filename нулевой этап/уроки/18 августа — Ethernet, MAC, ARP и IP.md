# 18 августа — Ethernet, MAC, ARP и IP

**Цель:** понять взаимодействие канального и сетевого уровней. **Результат:** покадровое объяснение отправки пакета в своей и другой подсети.

## Теория и команды

Ethernet доставляет кадры в локальном сегменте по MAC; IP адресует узлы между сетями; ARP сопоставляет локальный IPv4 с MAC. Для удалённого IP кадр отправляется MAC-адресу шлюза, а IP назначения сохраняется.

- `ip link` — интерфейсы и MAC; `ip addr` — IP.
- `ip neigh` — таблица соседей/ARP-кэш.
- `ip route` — выбор следующего перехода.

## Безопасная практика

Запиши MAC/IP хоста, VM и шлюза. Выполни разрешённый обмен с VM, сравни `ip neigh` до и после. Нарисуй кадр и пакет для обращения к VM и внешнему адресу без сканирования чужих систем.
