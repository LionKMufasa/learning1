# 25 августа — Python: прикладной минимум

**Цель:** подготовить основу CLI-инструмента. **Результат:** программа принимает аргументы, обрабатывает ошибки и сохраняет JSON.

## Теория и конструкции

Повтори `str`, `int`, `list`, `dict`, `tuple`, `set`, `if`, `for`, функции и `try/except`. Используй `pathlib` для путей, `argparse` для CLI, `json` для структурированного результата. Создай виртуальное окружение: `python3 -m venv .venv`; активируй только внутри каталога проекта.

## Безопасная практика

Напиши локальную CLI-заготовку, которая принимает `--host`, `--ports` и `--output`, проверяет формат списка портов и сохраняет входные данные с временем запуска в JSON. Сегодня сетевых подключений нет. Пароли и токены не записывай.

2. Какие ошибки нужно сообщать пользователю без traceback?
3. Почему JSON удобнее неструктурированного текста?
