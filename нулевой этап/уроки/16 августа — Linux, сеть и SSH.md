# 16 августа — Linux: сеть и SSH

**Цель:** связать интерфейс, маршрут, SSH, HTTP и журналы. **Результат:** подключение с хоста к VM и найденный HTTP-запрос.

## Теория и команды

- `ip addr` — адреса интерфейсов; `ip route` — таблица маршрутизации.
- `ss -tulpn` — открытые локальные сокеты.
- `ping` — ICMP-проверка; отсутствие ответа не доказывает недоступность.
- `ssh user@IP` — защищённая удалённая оболочка.
- `curl -i http://IP` — HTTP-ответ вместе с заголовками.

## Безопасная практика

Настрой SSH только в учебной VM. Подключись с основного компьютера, запроси Nginx через `curl`, найди этот запрос в access log. Зафиксируй IP, маршрут, порты 22/80 и связанные процессы.
