# 29 августа — первая Web-безопасность

**Цель:** применить HTTP-модель в легальных лабораториях. **Результат:** 3–5 начальных заданий и собственные объяснения причин.

## Теория

Начни с access control и authentication; затем по одному вводному заданию SQL injection и path traversal. Для каждого различай вход, опасную обработку, нарушение свойства безопасности, наблюдаемое доказательство и защиту.

## Безопасная практика

Используй только PortSwigger Web Security Academy или локальное намеренно уязвимое приложение. Перед началом запиши правила платформы. Не повторяй техники на реальных сайтах. Не копируй walkthrough до первой самостоятельной гипотезы.

## Самопроверка

1. Какая граница доверия нарушена?
2. Как доказательство минимизирует влияние?
3. Какая защита устраняет первопричину, а не симптом?
