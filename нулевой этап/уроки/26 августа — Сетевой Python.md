# 26 августа — сетевой Python

**Цель:** понять TCP-сокеты и HTTP-клиент. **Результат:** небольшой инструмент только для собственного стенда.

## Теория

`socket.create_connection((host, port), timeout=...)` устанавливает TCP-соединение; закрывай сокет через context manager. `requests.get(url, timeout=...)` выполняет HTTP-запрос; всегда задавай timeout. Отличай DNS-ошибку, отказ соединения и таймаут.

## Безопасная практика

Расширь вчерашнюю программу: разреши только явно переданный адрес собственной VM и небольшой список портов; сохрани успешные соединения и ошибки в JSON. Второй режим получает с Nginx status code, `Server` и `Content-Type`. Не добавляй параллелизм, обход подсетей или скрытность.
