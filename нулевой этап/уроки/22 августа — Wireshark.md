# 22 августа — Wireshark

**Цель:** читать базовые сетевые обмены. **Результат:** единый разбор ARP, DNS, TCP и HTTP из собственного трафика.

## Теория и фильтры

Capture filter ограничивает запись, display filter — отображение уже записанного. Основные display-фильтры: `arp`, `dns`, `icmp`, `tcp.flags.syn == 1`, `http`, `ip.addr == VM_IP`.

## Безопасная практика

Сними трафик только своего хоста/VM. Сгенерируй ARP-соседство, DNS-запрос, ping и HTTP-запрос к Nginx. Для каждого события зафиксируй MAC, IP, порты, протокол, полезную нагрузку и место в последовательности. В HTTPS содержимое приложения не должно читаться открыто.

2. Как связать DNS-ответ с последующим TCP-соединением?
3. Какие части HTTPS всё ещё наблюдаемы без расшифровки?
