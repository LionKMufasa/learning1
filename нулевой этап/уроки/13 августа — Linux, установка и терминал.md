# 13 августа — Linux: установка и терминал

**Цель:** запустить Ubuntu Server VM и уверенно перемещаться по файловой системе. **Результат:** VM с NAT, обычным пользователем и каталогом `~/study`.

## Теория и команды

Разбери назначение `/`, `/etc`, `/home`, `/var`, `/usr`, `/tmp`, `/proc`, `/dev`.

- `pwd` — текущий каталог; `ls -la` — все элементы с правами.
- `cd`, `mkdir`, `touch` — переход, каталог, пустой файл.
- `cp`, `mv`, `rm` — копирование, перемещение, удаление; перед `rm` всегда проверяй путь.
- `cat`, `less`, `head`, `tail` — чтение файлов.
- `find`, `which`, `file`, `man`, `history` — поиск и справка.

## Безопасная практика

Создай Ubuntu Server VM: 2 CPU, 3–4 GB RAM, 25–30 GB диска, сеть NAT. В `~/study` создай `linux`, `network`, `scripts`; создай, найди, скопируй, перемести и удали тестовый файл. Не используй реальные секреты.
