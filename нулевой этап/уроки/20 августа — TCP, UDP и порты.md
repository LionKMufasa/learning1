# 20 августа — TCP, UDP и порты

**Цель:** понять транспортный уровень. **Результат:** разбор TCP handshake и осмысленное сравнение TCP/UDP.

## Теория и команды

TCP устанавливает соединение `SYN → SYN/ACK → ACK`, нумерует данные, подтверждает получение и повторяет потерянное. UDP отправляет датаграммы без этих гарантий. Пара IP:порт определяет конечную точку; клиентский порт обычно временный.

- `ss -tn` — TCP-соединения; `ss -lun` — UDP-сокеты.
- `curl http://VM_IP` — инициировать TCP/HTTP к своей VM.
- `tcpdump -nn -i INTERFACE tcp port 80` — числа без DNS, выбранный интерфейс, только TCP/80.

## Безопасная практика

На VM перехвати собственный запрос к Nginx. Найди SYN, SYN/ACK, ACK, клиентский и серверный порты. Сопоставь захват с `ss`; не перехватывай чужой трафик.
