# Карта знаний

## Цель

К началу магистратуры сформировать прочный фундамент по компьютерным сетям, операционным системам, программированию и безопасности; научиться методично проводить тестирование в разрешённой среде и ясно оформлять результаты.

Текущий маршрут — [[05 — План 13–31 августа]]. Начинаем с первого незавершённого урока: календарная задержка не является поводом пропускать фундамент.

## Маршрут обучения

### 1. Фундамент

- [ ] Linux: файловая система, процессы, права, службы, журналы
- [ ] Сети: OSI/TCP-IP, IPv4/IPv6, ARP, DNS, DHCP, маршрутизация
- [ ] Web: HTTP(S), cookies, sessions, SOP/CORS, REST
- [ ] Программирование: Python, Bash, Git, чтение чужого кода
- [ ] Криптография: хеширование, шифрование, подписи, TLS

### 2. Методология безопасности

- [ ] Модели угроз и поверхность атаки
- [ ] Разведка и инвентаризация в пределах разрешённого scope
- [ ] Анализ конфигурации и уязвимостей
- [ ] Проверка гипотез в лаборатории
- [ ] Оценка риска, доказательства и отчётность
- [ ] Рекомендации по устранению и повторная проверка

### 3. Основные направления

- [ ] Безопасность веб-приложений
- [ ] Безопасность Linux и Windows
- [ ] Сетевой пентест
- [ ] Active Directory
- [ ] Контейнеры и облака
- [ ] Безопасность исходного кода

## Рабочий цикл темы

`Вопрос → теория → безопасная лаборатория → собственное объяснение → шпаргалка → повторение`
