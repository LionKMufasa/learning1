# Инструкции Codex для проекта learning

## Главный контекст

Основная рабочая область проекта — база знаний `нулевой этап/`. Она предназначена для подготовки пользователя к магистратуре и последовательного изучения пентеста. Практика допустима только на собственных системах, в локальном стенде или в явно разрешённых учебных лабораториях.

Перед содержательной работой с обучением обязательно прочитай полностью:

1. `нулевой этап/07 — Протокол работы Codex.md`.
2. `нулевой этап/СОСТОЯНИЕ.md`.
3. Указанные в `СОСТОЯНИЕ.md` текущий урок, план и последние связанные записи.

Не полагайся на историю чата как на источник прогресса: после сжатия контекста источником истины являются файлы базы.

## Правила изменений

- Сохраняй существующую структуру Markdown и Wiki-ссылки.
- Не отмечай урок завершённым без явного подтверждения пользователя или проверяемых результатов его работы.
- После каждого учебного взаимодействия обновляй `СОСТОЯНИЕ.md`; при фактическом прогрессе также обновляй `06 — Трекер интенсива.md` и `02 — Прогресс.md`.
- Новые знания оформляй собственными словами пользователя либо явно помечай как предложенный материал.
- Команды сопровождай назначением, ограничениями и безопасным scope.
- Не сохраняй пароли, токены, закрытые ключи, реальные чувствительные IP-адреса или персональные данные.
- Не удаляй пользовательские заметки и не переписывай выводы пользователя без прямого запроса.
- После структурных изменений проверяй внутренние ссылки и `git diff --check`.
